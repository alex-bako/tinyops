# M1.T1 — Invitee Join flow

Objective: a signed-in user with a pending invitation and no membership sees the Join flow, enters their name, accepts, and lands in the invited workspace as an onboarded member (INV-3, INV-4, INV-8 message, INV-11). Exclusions: no email, no copy-link, no switcher changes.

## Acceptance mapping
| Acceptance (M1.md) | Where |
| --- | --- |
| pending invite + no membership → Join, not onboarding | `app/onboarding/page.tsx` redirects to `JOIN_PATH` when no workspace and ≥1 joinable invitation (single chokepoint: `(app)/layout.tsx` already sends every non-ready user there) |
| name + Accept → membership, `profiles.onboarded_at`, invitation accepted, redirect | migration extends `accept_workspace_invitation` with optional `target_first_name`/`target_last_name`; sets names + `onboarded_at = coalesce(onboarded_at, now())` atomically |
| revoked before Accept → "This invite is no longer valid", nothing created | RPC raises `Workspace invitation not found`; Join flow shows message + sign-out |
| existing membership → routing unchanged | `app/join/page.tsx` redirects members to `/home`; onboarding page only diverts when `workspaces.length === 0` |
| no invite + no membership → onboarding as today | unchanged branch |
| existing Auth user, no membership → same user joins (INV-11) | RPC updates the actor's existing profile row; no user/profile creation |

## Illustrative RPC tail (verify against migration)
```sql
update public.profiles
set first_name = coalesce(nullif(btrim(target_first_name), ''), first_name),
    last_name  = coalesce(nullif(btrim(target_last_name), ''), last_name),
    onboarded_at = coalesce(onboarded_at, now())
where id = actor_id;
```

## Failure / security
- RPC stays security definer with `search_path=''`; JWT email must equal invitation email (unchanged).
- Join page never trusts client-provided workspace ids; the RPC re-checks ownership of the invitation by email.
- Accept errors map to `workspace_action_failed` → UI shows the neutral "no longer valid" message.
